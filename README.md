# Squad404 — додаток першокурсника

Стек: C# / ASP.NET Core Web API (сервер), .NET MAUI + XAML (клієнт).
Це початкова структура. API, MAUI-проєкт і база ще не створені.

| Папка | Призначення |
|---|---|
| backend/ | API. Тут створюємо проєкт Squad404.Api |
| client/ | Майбутній MAUI-проєкт |
| database/ | Схема бази та документація другого бекендера |
| design/ | Макети та експорт із Figma |
| assets/ | Спільні зображення та матеріали |
| logos/ | Логотипи |

Файли .gitkeep зберігають порожні папки в Git. bin/ та obj/ — автоматичні файли збірки, вони ігноруються.

## Гілки

- main — стабільна версія.
- develop — інтеграція роботи команди.
- api — перше завдання бекенду: endpoint логіну.

Працюємо в робочих гілках, зміни пропонуємо через Pull Request.
Це домовленість команди; правила захисту гілок автоматично не налаштовані.

## Початок роботи над API

Потрібен .NET 10 SDK. У терміналі:

```bash
git clone https://github.com/f1lef/project.git
cd project
git switch api
dotnet --version
dotnet new web -n Squad404.Api -o backend/Squad404.Api --framework net10.0
dotnet run --project backend/Squad404.Api --urls http://localhost:5050
```

Після запуску відкрий http://localhost:5050 — шаблон поверне Hello World!
Зупинка сервера: Ctrl+C.

dotnet new web створює мінімальний ASP.NET Core проєкт, на основі якого пишемо API.
Головний файл: backend/Squad404.Api/Program.cs.

## Перше завдання: логін

Endpoint: POST /api/auth/login.
Тіло запиту: JSON із полями email та password.

Очікувані результати:
- 400 — поля порожні або некоректні;
- 401 — неправильні облікові дані;
- 200 — правильні облікові дані.

На першому навчальному етапі можна перевіряти тестового користувача без БД, якщо це відповідає вимогам викладача.
Відповідь 200 сама по собі ще не створює автентифіковану сесію.
Для справжнього входу потрібні сесія або токен і захист наступних запитів.
Не зберігайте реальні паролі в коді чи Git; для збережених користувачів використовуйте готові засоби ASP.NET Core Identity.

MAUI-екран не потрібен для першої перевірки API: використовуйте Postman або HTTP-клієнт редактора.
MAUI-проєкт створюється окремо в client/. Дані спільної бази зберігаються на сервері.
